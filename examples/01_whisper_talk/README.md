## 再現するコマンド

このフォルダで実行します（出力がすでにある場合は `--overwrite` を付けます）。

```bash
python3 ../../scripts/inspect_srt.py input.srt --glossary glossary.json --template candidates.json
python3 ../../scripts/apply_candidates.py input.srt candidates.json --glossary glossary.json --out-dir output
python3 ../../scripts/verify_srt.py input.srt output/input.polished.srt --log output/input.apply-log.json
# 句読点を外したテロップ表記（output_telop）
python3 ../../scripts/apply_candidates.py input.srt candidates.json --glossary glossary.json --punct telop --out-dir output_telop
```

機械検査（件数・番号・順番・時刻・BOM・改行コード）は すべての出力で一致しています。日本語の意味・読みやすさ・映像との同期は、この検査の対象外です。
