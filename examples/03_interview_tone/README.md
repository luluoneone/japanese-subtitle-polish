# 関西弁のインタビュー字幕

話者の口調（「〜へん」「ええねん」）、否定、「くらい」「感じですかね」のぼかしを保ちます。「子供／子ども」の表記ゆれと、辞書にない人名「ヤマダさん」は要確認です。`output_fillers/` は、利用者がフィラー削除を選んだ場合の結果です（「えっと、」「まあ、」だけを削除し、「いやー」は気持ちを表す言葉として残しています）。

字幕・辞書・人名は架空です。`candidates.json` は、このSkillの手順に沿ってAI（Claude）が作った修正候補です。

## ファイル

|---|---|

| `candidates.json` | 修正候補 |

## 再現するコマンド

このフォルダで実行します（出力がすでにある場合は `--overwrite` を付けます）。

```bash
python3 ../../scripts/apply_candidates.py input.srt candidates.json --out-dir output
python3 ../../scripts/apply_candidates.py input.srt candidates_with_fillers.json --allow フィラー削除 --out-dir output_fillers
python3 ../../scripts/verify_srt.py input.srt output/input.polished.srt --log output/input.apply-log.json
```

機械検査（件数・番号・順番・時刻・BOM・改行コード）は すべての出力で一致しています。日本語の意味・読みやすさ・映像との同期は、この検査の対象外です。
