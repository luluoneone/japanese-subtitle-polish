# 辞書（固有名詞の一覧）の作り方

辞書には「正しい表記」と「音声認識が出しがちな書き方」を並べます。辞書にある語は、

- inspect で自動的に候補になる（AIが文脈を確かめてから適用）
- 改行で途中を分けない

という2つの扱いを受けます。辞書は任意です。

## JSON

```json
{
  "terms": [
    {"correct": "Premiere Pro", "variants": ["プレミアプロ", "premiere pro"], "note": "Adobeの編集ソフト"},
    {"correct": "DaVinci Resolve", "variants": ["ダビンチリゾルブ", "ダヴィンチリゾルブ"]}
  ]
}
```

## TSV（表計算ソフトで作る場合）

タブ区切りで「正式表記」「誤表記（`|` 区切り）」「メモ」を並べます。`#` で始まる行は読み飛ばします。UTF-8で保存してください。

```text
# 正式表記	誤表記	メモ
Premiere Pro	プレミアプロ|premiere pro	Adobeの編集ソフト
LUT	ラット|ルット
```

## 一致のしかた

- 英字の語は、大文字・小文字を区別せずに探します（`premiere pro` も `Premiere pro` も一致）。単語の途中には一致しません（`ae` は `aerial` に一致しない）。
- 英字の正式表記そのものも、大文字・小文字が違えば候補になります（`youtube` → `YouTube`）。
- カタカナの誤表記は、カタカナ語の途中には一致しません（`ラット` は `フラット` に一致しない）。
- 漢字・ひらがなの誤表記は、文字列として一致した箇所すべてが候補になります。短すぎる誤表記は誤一致しやすいので、2〜3字以上にしてください。
