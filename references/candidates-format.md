# 修正候補ファイルの形式

`inspect_srt.py --template` で下書きを作り、`candidates` に候補を追記します。UTF-8のJSONです。

```json
{
  "schema": "japanese-subtitle-polish/candidates-v1",
  "source_file": "input.srt",
  "source_sha256": "9424e8221e44…",
  "candidates": [
    {
      "id": "C001",
      "index": 3,
      "start": "00:00:08,400",
      "type": "誤変換",
      "original": "以外と大事",
      "proposed": "意外と大事",
      "reason": "「以外と大事」は文として成り立たない。「意外と」の変換ミス",
      "evidence": "文脈：同じ字幕の「〜ので意外と大事なんですよね」",
      "status": "apply"
    }
  ]
}
```

## 項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `source_sha256` | 推奨 | 候補を作ったSRTのSHA-256。適用時に一致しなければ**全候補を適用せず終了**する（別の版のSRTへの誤適用を防ぐ） |
| `id` | 必須 | 候補の識別子。重複不可。AIの候補は `C001`、辞書由来は `G001`、フィラーは `F001` など |
| `index` | 必須 | SRTの字幕番号 |
| `start` | 推奨 | 字幕の開始時刻（inspect の表示どおり）。一致しなければ適用しない |
| `type` | 必須 | `誤字` `誤変換` `表記ゆれ` `固有名詞` `句読点` `改行` `フィラー削除` `要約` `手動修正` のどれか。`手動修正` は確認画面で利用者が直したもの（`approved: true` が必要）。`status: "review"` の候補だけは `その他` も使える |
| `original` | 必須 | 直す前の文字列。改行を外した本文から一字一句写す |
| `proposed` | 必須 | 直したあとの文字列 |
| `reason` | 必須 | なぜ直すか |
| `evidence` | 必須 | 何で確かめたか（要確認の場合は、何で確かめればよいか） |
| `status` | 必須 | `apply`（適用する）か `review`（要確認。適用しない） |
| `scope` | 任意 | `span`（初期値。本文の一部を置き換える）か `cue`（字幕全体を置き換える） |
| `approved` | 任意 | `true` は「安全チェックに止められた候補を、利用者が確認して承認した」という意味。確認画面で保存した候補には付いている。AIが自分の判断で付けない |

## 照合のルール

スクリプトは候補ごとに次を確かめ、一つでも合わなければその候補を適用しません（理由は要確認一覧に出ます）。

1. 候補ファイルの `source_sha256` が対象SRTと一致する（不一致なら全体を中止）
2. `index` の字幕が1件だけある（同じ番号が複数あれば曖昧として不採用）
3. `start` があれば、その字幕の開始時刻と一致する
4. `scope: "span"` では、`original` がその字幕の本文にちょうど1回だけ現れる
   - 0回：原文不一致として不採用
   - 2回以上：対象が曖昧として不採用（前後の文字を含めて書き直す）
5. `scope: "cue"` では、`original` が字幕の本文全体と一致する
6. 同じ字幕の中で、ほかの候補と範囲が重ならない
7. 修正後の本文が空にならず、`-->` を含まない
8. 安全チェック（数字・単位・否定・断定の強さ・語尾・フィラー・大きな削除）に当たらない。当たった場合は `approved: true` のときだけ適用
9. `フィラー削除`・`要約` は、`--allow` で選んだときだけ適用

## 本文の扱い

`original` と比べる本文は「改行を外した本文」です。inspect の一覧に出る文字列と同じで、

- 日本語の行どうしは、そのままつなぎます（「今日は撮影の」＋「基本です」→「今日は撮影の基本です」）。
- 英数字どうしの改行は、半角スペース1つとしてつなぎます（「Premiere」＋「Pro」→「Premiere Pro」）。

## 例

字幕全体を置き換える（同じ語が2回あるときなど）:

```json
{"id": "C004", "index": 5, "scope": "cue", "type": "固有名詞",
 "original": "ラットを当ててからラットの強さを下げます",
 "proposed": "LUTを当ててからLUTの強さを下げます",
 "reason": "辞書の正式表記にそろえる", "evidence": "辞書: LUT ← ラット", "status": "apply"}
```

要確認（候補が決められない）:

```json
{"id": "C005", "index": 7, "type": "固有名詞", "original": "ヤマダさん", "proposed": "",
 "reason": "人名。漢字表記が分からないためカタカナのまま残した",
 "evidence": "辞書に登録なし。本人・取材メモで確認する", "status": "review"}
```

改行だけを指定する:

```json
{"id": "C006", "index": 9, "scope": "cue", "type": "改行",
 "original": "ログ素材には変換用のLUTを先に当てます",
 "proposed": "ログ素材には\n変換用のLUTを先に当てます",
 "reason": "「ログ素材には」で意味が切れる", "evidence": "改行位置の判断のみ。本文は同じ", "status": "apply"}
```
