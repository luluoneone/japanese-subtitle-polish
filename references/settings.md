# 設定と初期値

設定は「プリセット → `--config` の設定ファイル → コマンドの指定」の順に上書きされます。

```bash
# プリセットを選ぶ
python3 scripts/apply_candidates.py input.srt input.candidates.json --preset safe
# 一部だけ変える
python3 scripts/apply_candidates.py input.srt input.candidates.json --max-chars 18 --max-cps 7
# 設定ファイルで変える（config/example.config.json を参照）
python3 scripts/apply_candidates.py input.srt input.candidates.json --config my.json
```

## 文字の大きさから1行の字数を決める（おすすめ）

字幕の文字の大きさは人によって違うので、字数を決め打ちするより、**動画のサイズと文字の大きさ**を指定するのがおすすめです。

```bash
python3 scripts/apply_candidates.py input.srt input.candidates.json --video-size 1920x1080 --font-size 80
```

1行の字数 ＝ 動画の横幅のうち、左右5%ずつ空けた幅 ÷ 文字の大きさ（全角1字の幅を文字の大きさと同じとみなす）。

| 動画のサイズ | 文字の大きさ | 1行の字数 |
|---|---|---|
| 1920×1080 | 60px | 28字 |
| 1920×1080 | 80px | 21字 |
| 1920×1080 | 100px | 17字 |
| 1080×1920（縦型） | 80px | 12字 |
| 3840×2160（4K） | 160px | 21字 |

文字の大きさは、編集ソフトでそのサイズのシーケンスに字幕を置いたときのフォントサイズ（px）です。
ソフトやフォントによって実際の幅は少し違うので、確認画面と編集ソフトで見え方を確かめてください。
`--font-size` を指定すると、`--max-chars` とプリセットの字数より優先されます。

## 項目と初期値

| 項目 | コマンド | 初期値（standard） | 内容 |
|---|---|---|---|
| `max_lines` | `--max-lines` | 2 | 1つの字幕の最大行数 |
| `max_chars_per_line` | `--max-chars` | 16 | 1行の最大文字数（数え方は下記）。`font_px` があればそこから計算 |
| `video_size` | `--video-size` | なし | 動画のサイズ（例 `1920x1080`） |
| `font_px` | `--font-size` | なし | 字幕の文字の大きさ（動画のピクセル） |
| `halfwidth_weight` | 設定ファイル | 0.5 | 半角文字を何文字と数えるか |
| `max_cps` | `--max-cps` | 6.0 | 見やすさの目安（1秒あたりの文字数）。超えた字幕を「目安より速い」として報告する。0 で報告しない |
| `min_line_chars` | 設定ファイル | 2 | これより短い行（「ね」だけの行など）を作りにくくする |
| `linebreak_mode` | `--linebreak` | `auto` | 改行の整え方（下記） |
| `punctuation` | `--punct` | `keep` | `telop` にすると句読点・かっこを外す（テロップ表記） |
| `punct_keep` | `--punct-keep` | `ー－−—―‐-…‥！!？?〜～` | `telop` のときに残す記号 |
| `allow_types` | `--allow` | なし | 標準では行わない種類（`フィラー削除`・`要約`）を許可 |
| `protect_terms` | 設定ファイル | なし | 改行で分けない語（辞書の正式表記は自動で守られる） |

## プリセット

| プリセット | 行数 | 1行 | 1秒あたり | 向いている場面 |
|---|---|---|---|---|
| `genba` | 2 | 15字 | 4字 | 映像制作の現場基準（1行12〜15字・2行まで・1秒4字）。アプリの初期値 |
| `standard` | 2 | 16字 | 6字 | 横長（16:9）の解説・トーク動画。Skillの初期値 |
| `safe` | 2 | 13字 | 4字 | 翻訳字幕、高齢の視聴者、教育・重要な情報など、読みやすさを優先する場合 |
| `vertical` | 2 | 12字 | 6字 | 縦型（9:16）のショート動画。画面の幅が狭いため1行を短くする |

### 値の考え方

- **映像制作の現場基準**として、1秒4字を読む速さの安全側の開始点、1行12〜15字前後、2行までを使います（`genba`）。
  1秒6字が読める視聴者・媒体もありますが、短時間に文字が増えるほど理解の負担が上がります。高齢の視聴者、教育、重要な情報では安全側にしてください。
- **1秒4字**は、読む速さとして安全側の目安です。ただ、話し言葉をそのまま文字にした字幕は4字を超えやすく、
  4字を基準にすると多くの字幕に印が付きます。目安なので誤りではありません。そこで `standard` では、
  速く読める視聴者でも負担が大きくなる**6字を超えたもの**だけを報告します。読みやすさを優先する場合は `safe` を使ってください。
  どの値もルールではなく目安です。利用者が選べるようにしてあり（アプリでは 4・6・8字・知らせない）、確認画面でもその場で切り替えられます。
- **1行の文字数**は、映像の解像度ではなく、字幕の文字の大きさと画面の幅で決まります。
  編集ソフトで実際に表示し、はみ出す・小さすぎる場合は `--max-chars` を変えてください。
- どの値も、媒体・視聴者・クライアントの指定があればそちらを優先します。法律や全媒体共通の基準ではありません。

## 文字数の数え方

- 全角文字（漢字・かな・全角記号）は1字、半角文字（英数字・半角記号）は `halfwidth_weight`（初期値0.5）字として数えます。
  「Premiere Pro」は12文字なので6字です。
- 1秒あたりの文字数は、空白と改行を除いた文字数を、表示時間（終了時刻−開始時刻）で割ります。
- `<i>` などのタグと、ASS形式の `{\an8}` は数えません。
- **実際の表示幅（フォントのピクセル幅）は測っていません。** プロポーショナルフォントでは、同じ字数でも幅が変わります。

## 改行モード

| モード | 動き |
|---|---|
| `auto`（初期値） | 元の改行に問題がなければ残す。行数・文字数の超過や語の途中の改行がある字幕と、修正で改行が崩れた字幕だけ整える |
| `keep` | 元の改行を変えない（修正した字幕でも、できるだけ元の行の形を保つ）。問題は要確認に出す |
| `all` | すべての字幕を設定に合わせて改行し直す |

改行位置は、句読点・空白・助詞のあとを優先し、次の位置を避けて選びます。

- 英単語・数字の途中、数字と単位の間（「100／%」「4／K」）
- カタカナ語・漢字の熟語の途中（「ルックアップテー／ブル」）、送り仮名の途中（「書き／出し」）
- 行頭の句読点・閉じかっこ・小さい「っ」「ゃ」・長音「ー」、行末の開きかっこ
- 行頭の助動詞（「なら／ない」）、て形と補助動詞の間（「教えても／らった」）
- 「この」「その」など、次の名詞にかかる語の直後
- 辞書の正式表記と `protect_terms` の途中

上限内でこれらを避けられない場合は、上限を少し超えても語の途中で切らない案を選び、要確認一覧の「上限に収まらない字幕」に出します。
字幕を2つに分けると時刻が変わるため、分割はしません。

形態素解析器は使わず、文字の種類と規則で判断しています。ひらがなが続く部分では、まれに不自然な位置で切ることがあります。
